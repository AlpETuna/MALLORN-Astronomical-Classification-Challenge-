# MALLORN Astronomical Classification Challenge

## Overview

This project provides a machine learning pipeline for the **MALLORN Astronomical Classification Challenge**. The goal is to classify **Tidal Disruption Events (TDEs)** from lightcurve data collected by the LSST (Legacy Survey of Space and Time).

The solution utilizes advanced feature engineering from time-series photometry and a hyperparameter-tuned **XGBoost Classifier** to distinguish TDEs from other transients like AGN and Supernovae.
